# 路线图

赛题要求、实现状态和验收分开记录。负责人由队员认领 Issue 后确定。

| 顺序 | 工作 | 验收条件 |
|---|---|---|
| P0 | 当前模块拆分源码重构建 | RTL 仿真、综合/布局布线、引脚与时序复核；记录源码 commit 与新产物哈希；匹配软件后再上板 |
| P1 | 摄像头真实帧接人员分类 | 明确 DDR 三缓冲所有权和 cache 管理；96×96 灰度 INT8；真实 Invoke；结果关联帧号、时间戳和耗时；不阻塞视频/红外 |
| P1 | FPGA 帧差运动分析 | 静止、运动和光照变化可重复测试；运动量与帧号/时间戳输出，验证实际运行在 FPGA 端 |
| P1 | 场景选择、融合与本地报警 | 先选定一个场景；定义融合输入、有效期、阈值/迟滞及失联处理；LED、蜂鸣器、HDMI 红框、事件类型/置信度逐项验证 |
| P2 | 任务 3 至少两项扩展 | 从指南选项中选两项，分别定义交付与验收；现有 RISC-V 推理不能自动算作复杂决策扩展完成 |
| P2 | 长时回归及独立运行 | 完整负载下视频/红外/环境/AI/报警并发稳定；分开统计采集帧率、显示刷新和推理吞吐；Flash 固化另行确认 |
| 暂缓 | SHT 日志异常 | 用户当前明确暂不处理，恢复调查时保留原始证据并复现 |
| 暂缓 | 清晰度/对焦 | 不把模糊直接确认为缺少自动对焦 |
| 资料待补 | 真正的摄像头 ≥60fps | 获取匹配模组的完整寄存器模式表，核对 lane/位深/带宽/曝光，再评估资源与实测 |

赛题任务 1 基础门槛为 MIPI 视频不低于 720p@30fps，还需要预处理、异常值处理与时间戳对齐；现有同屏显示不是任务 1 的全部验收。任务 2 需运动分析、多模态决策和本地报警。任务 3 可选千兆以太网上报、RISC-V 复杂决策/协议、多目标跟踪、行为预测、低功耗、Web 监控、SPI 语音，至少两项。具体场景和两项扩展尚待团队确定。
