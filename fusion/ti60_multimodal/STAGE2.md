## 图像通路

SC431HAI 四 lane RAW10 → 取高 8 位、饱和减黑电平 16 → 四个完整行缓存 → BGGR 5×5 去马赛克、原 255/256 色彩增益 → 原 1/2.2 Gamma → 全视野 3:2 缩放 → RGB565 三缓冲 DDR → HDMI 视频窗。

- 摄像头初始化、曝光 2989 半行、模拟 6.16 倍、数字 1 倍均沿用已验证参数。启动阶段仍先输出测试图，随后转实景；没有增加自动对焦、自动曝光或锐化。
- CSI 像素域 50 MHz、4 像素/拍；完整行在 DDR core 100 MHz 域以 2 像素/拍连续送入 ISP。不能将带间隙的 DE 直接送给原 ISP，因为原模块以 DE 下降沿判断行结束。
- 行 RAM 的槽位直到最后一对像素读取完成后才释放。输入按每 480 个有效 RAW 组形成一行，允许 CSI DE 内部有空隙；输出给 ISP 的每行保持连续。有效帧须满足 1920×1080 个像素、RAW10、4 像素/拍、WC=2400；总像素不足、格式异常、溢出均使该帧无效。当前按总像素数重组行，不能声称检测到了所有可能的逐包丢失/增补组合。
- 摄像头原 `simple_dual_port_ram` 为两拍读延迟，SoC 同名模块是一拍。融合版使用独立 `camera_line_ram`，避免改变任一原模块的时序。原空间滤波保留约两行、两列的内容偏移和边界策略，未将此版称为清晰度修复。
- 显示缩放为最近邻，坐标 `source=floor(destination*3/2)`，保持完整视野和 16:9 比例。RGB565 是显示缓存格式；没有宣称抗混叠缩放、完整 ISP 画质验收或实时 AI 输入完成。
- 复用的 `DC_FIFO` 仅在融合副本修正了 GrayDecode：采用连续 XOR 赋值，避免仿真初始零指针不触发事件而使数量未知。原来源文件不修改。

## 内存和帧所有权

| 用途 | 地址 | 当前使用 |
|---|---|---|
| 程序、堆栈、模型预留 | `0x00001000..0x03FFFFFF` | 固件链接限制在此区间 |
| 原 RAW 预留区 | `0x04000000..0x05FFFFFF` | 阶段 2 不使用 |
| RGB565 bank 0 | `0x06000000..0x061C1FFF` | 1280×720×2 字节 |
| RGB565 bank 1 | `0x06200000..0x063C1FFF` | 同上 |
| RGB565 bank 2 | `0x06400000..0x065C1FFF` | 同上 |
| AI/运动预留 | `0x06800000..0x068FFFFF` | 尚未使用 |

视频通过原 interconnect 的 S1 主端访问同一 DDR。一个帧为 115,200 个 128-bit beat，正常事务每次 32 beat，512 字节对齐，不跨 4 KiB 边界。写入银行不等于当前显示银行或最新完整银行。所有帧数据、传感器结束记录、ISP 完整性和 AXI B 应答均成功，才发布新帧。

像素域在垂直消隐发出换帧请求；读控制器先结束旧读事务，再复位跨域显示 FIFO 并锁定最新银行。FIFO 下溢或 R 应答错误使本扫描无效，下一次消隐恢复。采集停止时，最新帧超过 1 秒不再作为有效输入；摄像头窗口使用无效背景。失去帧结束记录时写端有 50 ms 截止，丢弃未完成帧，不发布半帧。

当前 CPU 不读写图像缓存，尚无 CPU/AI 的 cache 一致性操作。后续使用实时图像时须增加真正的 cache 管理、帧号和银行所有权协议，不能用 `fence` 替代 invalidate。

## 摄像头状态寄存器

APB 基址 `0xF8100000`，阶段 1 的传感器接口不变；新增只读区：

| 偏移 | 含义 |
|---|---|
| `5000` | ID `43414D32` (`CAM2`) |
| `5004` | 初始化状态：bit0 enable、1 ID 通过、2 配置通过、3 stream、4 finished、7:5 error、15:8 command index |
| `5008 / 500C` | CSI 完整有效帧 / 异常帧数 |
| `5010 / 5014` | 帧周期（50 MHz tick）/ 行缓存溢出次数 |
| `5018 / 501C` | DDR 发布帧 / 丢弃帧数 |
| `5020 / 5024` | AXI 写 / 读错误数 |
| `5028 / 502C` | HDMI FIFO 下溢 / 最新发布帧号 |
| `5030 / 5034` | 最近完整帧有效像素数 / `{4'd0,VC[1:0],DT[5:0],PPC[3:0],WC[15:0]}` |
| `5038 / 503C` | 最近帧 DE 连续段数量 / `{11'd0,完整行数[10:0],行内组数[9:0]}` |
| `5040..5060` | 初始化末尾九个寄存器回读诊断字，低地址是最后读取的字 |

不同源时钟域使用冻结快照握手，每约 1 ms 请求一次；字段来自各自完整源快照，不是摄像头/红外/SHT 的统一采样时间戳。UART `CAM ms=...` 的 ms 是 CPU 日志时刻，尚不代表时间对齐已完成。
